# الرسائل الصوتية للتاجر (`src/voiceNotes`)

ميزة حصرية فـ **باقة الأعمال** (`features.merchantVoiceNotes` فـ `src/config/plans.js`): التاجر
يسجّل رسائل صوتية من بوت تيليغرام الخاص به، والبوت يبعثها تلقائيًا لزبائن فيسبوك ماسنجر
بدل (أو بالإضافة إلى) الرد النصي الجاهز.

## نوعان من الرسائل الصوتية

1. **صوتية خاصة بمنتج** - شرح المنتج وسعره وكل التفاصيل بصوت التاجر. تُحفظ كحقل مباشر على
   وثيقة المنتج (`voiceNoteUrl`, `voiceNoteFileId`, `voiceNoteDuration`) لأنها بيانات 1:1 مع
   المنتج، بلا داعي لمجموعة Firestore منفصلة.
   - تسجيلها: زر "🎙️ صوت شرح لمنتج" فـ قائمة المنتجات ← `attachProductVoiceScene.js`
   - إرسالها للزبون: مركزيًا من `catalogController.sendSingleProductCard` (تشتغل تلقائيًا
     فـ كل مكان يُستعمل فيه: القائمة الكاملة، البحث بالاسم، الرابط المباشر للمنتج).

2. **صوتية عامة لكل نية** (تحية، توصيل، ضمان، ألوان، مقارنة...) - رد صوتي واحد يُستعمل لكل
   الزبائن الذين تُكتشف نيتهم كذلك. تُخزَّن فـ `stores/{storeId}/voiceNotes/{intentKey}`
   (`VoiceNoteRepository.js`) لأنها منفصلة عن أي منتج معيّن.
   - تسجيلها: زر "🎙️ رسائل صوتية عامة" فـ الإعدادات ← لوحة اختيار نية (`voiceNoteKeyboards.js`)
     ← `attachIntentVoiceScene.js`
   - إرسالها: `catalogController.handleFreeText` يتحقق من `VoiceNoteService.getForIntent`
     بعد تحديد نية الزبون، قبل بناء أي رد نصي جاهز.

## القيود/قرارات التصميم

- **رابط الاستضافة**: نفس أسلوب صور المنتجات الحالي فـ المشروع بالضبط - نستعمل
  `ctx.telegram.getFileLink(fileId)` (رابط تليغرام مباشر) بدل رفع الملف لخدمة استضافة
  منفصلة. نفس الملاحظة الموجودة فـ `addProductScene.js` تنطبق هنا: إذا احتجت استقرارًا أفضل
  مستقبلاً، فكّر فـ Firebase Storage.
- **صوتية المنتج**: تُرسل دائمًا **إضافة** لبطاقة المنتج (نص + صورة + زر الشراء) - ماشي بديل
  عنها، لأن زر "🛒 اطلب الآن" ضروري لإتمام الطلب ولا يوجد فـ الصوت.
- **صوتية النية**: تحل **محل** الرد النصي الجاهز للنيات اللي عندها نص واحد بسيط (تحية، توصيل،
  وأي نية أخرى بلا معالجة خاصة). بالنسبة لـ "شراء" و"سعر" (اللي يفتحوا تدفق كامل: قائمة
  منتجات/بدء طلب)، الصوت يُرسل **كمقدمة** قبل إكمال نفس التدفق العادي، ماشي بديل عنه.
- **التخزين المؤقت**: `VoiceNoteService.getForIntent` يخزّن النتيجة 5 دقائق فـ الذاكرة (نفس
  نمط `src/learning`) لتفادي قراءة Firestore فـ كل رسالة زبون.
- **بوابة الباقة**: يُتحقّق منها فقط عند **التسجيل** (فـ الأدمن بوت، عبر
  `VoiceNoteService.isEnabled(store)`)، ماشي عند كل إرسال للزبون - إذا تجاوب التاجر لاحقًا
  لباقة أقل، الرسائل المسجَّلة سابقًا تبقى تشتغل (سلوك بسيط ومتوقَّع، بلا حذف مفاجئ لبيانات).
