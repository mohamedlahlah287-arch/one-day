## 🚀 بداية سريعة (تجربة محلية)

```bash
npm install
cp .env.example .env    # املأ التوكنات ومفاتيح Firebase
npm test                # تأكد أن كل شيء سليم
npm run start:merchant     # Terminal 1 - بوت التاجر
npm run start:customer     # Terminal 2 - بوت الزبائن
npm run start:superadmin   # Terminal 3 - بوت السوبر أدمن (أنت فقط)
```

## 🧩 الفكرة في سطرين

3 بوتات منفصلة تشترك في نفس منطق الأعمال (`src/services/`) ونفس قاعدة البيانات:
- **بوت السوبر أدمن** (Telegram، أنت فقط) — يضيف/يوقف/يحذف المتاجر، ويحدد/يجدد باقة كل متجر
- **بوت التاجر** (Telegram) — كل تاجر مسجَّل (من طرفك) يديره متجره منه (منتجات، طلبات، إحصائيات، إعدادات)
- **بوت الزبائن** (**Facebook Messenger**، وليس Telegram) — صفحة فيسبوك واحدة تخدم كل المتاجر
  عبر رابط خاص لكل تاجر: `m.me/اسم_صفحتك?ref=storeId`

⚠️ **التسجيل الذاتي معطّل عمدًا**: لا يقدر أي شخص يفتح متجرًا بنفسه. فقط أنت (عبر بوت السوبر أدمن)
تضيف تاجرًا جديدًا وتحدد له باقة.

⚠️ **بوت الزبائن يحتاج إعداد خاص**: بعكس بوتي التاجر والسوبر أدمن (تليغرام - تشغيل مباشر بتوكن)،
بوت الزبائن يحتاج تطبيق Facebook + صفحة + webhook عام (رابط HTTPS). راجع
[docs/FACEBOOK_SETUP.md](./docs/FACEBOOK_SETUP.md) للتفاصيل الكاملة خطوة بخطوة.

## 📦 باقات الاشتراك

معرّفة في `src/config/plans.js` (يمكنك تعديل الأسعار/الحدود من هناك):

| الباقة | الرسائل/شهر | حد المنتجات | صوت | صور | إحصائيات كاملة |
|---|---|---|---|---|---|
| المبتدئ | 300 | 15 | ❌ | ✅ | ❌ |
| المحترف | 1000 | 60 | ✅ | ✅ | ❌ |
| الأعمال | غير محدود | غير محدود | ✅ | ✅ | ✅ |

بالإضافة إلى **باقة مخصصة** يحددها السوبر أدمن بنفسه (عدد رسائل/أيام/مميزات حرة) عند إنشاء أو تعديل أي متجر.

عند انتهاء مدة الاشتراك، يتوقف المتجر تلقائيًا عن الرد (بلا حذف أي بيانات)، ويمكن تجديده بضغطة زر من
بوت السوبر أدمن. يمكن أيضًا إيقاف/تفعيل أي متجر يدويًا في أي وقت.

## 🎤🖼️ الرد الصوتي والتعرف على الصور (اختياري)

هذه المميزات تحتاج `GROQ_API_KEY` في متغيرات البيئة (مجاني للحصول عليه من [console.groq.com](https://console.groq.com)).
بدون هذا المفتاح، البوت يشتغل عادي، لكن يرد برسالة بديلة وينبّه التاجر بدل تفعيل الميزة.

## ⚠️ حالة المشروع

هذا نظام **جاهز معماريًا** (production-ready architecture) لكن **غير مجرب بعد تحت حمل حقيقي**.
قبل البيع لتجار حقيقيين، راجع قائمة التحقق في [docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md).

الأشياء الأساسية الناقصة عمدًا (تحتاج قرار عملي منك، ماشي كود إضافي فقط):
- نظام دفع/اشتراكات فعلي للتجار (`PaymentService` حاليًا Stub بانتظار مزود دفع جزائري)
- Redis حقيقي للطوابير (البنية جاهزة، فقط خاصك تفعّلها - راجع `src/queues/queue.js`)
